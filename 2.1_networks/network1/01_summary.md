## 📘 1. Summary of the Task

The goal of this lab is to understand how a Local Area Network (LAN) works and how multiple computers communicate with each other.

In this activity, I am expected to create a small LAN for five administrative staff members in a university building using Cisco Packet Tracer. I will connect five PCs to one 2960 switch using copper straight-through cables, assign each PC a unique IP address, and configure the same subnet mask.

Finally, I will use the ping command to test communication between the computers and check whether the network is working correctly.
